# Mixer2D 입력 편집

Mixer1D와 동일한 노드 편집 방식을 사용한다. 각 Pose 입력에 X/Y 샘플 좌표와 X 버튼을 표시하며, Add Input Pose로 입력을 추가한다. 첫 두 입력은 삭제할 수 없고 세 번째부터 삭제할 수 있다.

화면 이름은 Pose1, Pose2, Pose3 순서로 표시한다. 연결에 쓰는 기존 포트 ID는 유지하므로 GUID 이름을 사용하는 기존 입력과 연결도 보존한다. 좌표 변경·입력 추가·삭제는 그래프 전체 Undo/Redo 및 임베디드 소스 저장을 사용한다.

세부 Mixer2D Inspector는 노드 우클릭 메뉴에서 연다. 2D 블렌딩 계산과 입력 바인딩 방식은 변경하지 않는다.

검증: Mixer2D 21개 검사, Mixer1D 회귀 21개 검사, 기존 전체 기능 41개 검사 통과. 컴파일 경고·오류 없음.
