# UAnimGraph 구현·검증 결과

실제 프로젝트: `C:\Homework\UAnimGraph`
구현 위치: `Assets/UAnimGraph/MVP`
검증 Unity 버전: **7000.0.0a9**

## 이번 작업에서 추가·보완한 항목

- 선택한 디버그 캐릭터의 활성 Pose 노드, State, 전이를 Graph Toolkit 시각화 API로 표시한다. 가중치와 전이 진행률을 반영하며, 대상 변경과 창 종료 때 해제한다.
- 열린 그래프에만 표시를 적용하여 Unity 7 alpha의 닫힌 그래프 시각화 예외를 피한다.
- Graph Toolkit 오류 메시지에 해당 노드·State 문맥을 연결했다. 출력, 참조, Parameter ID, Threshold 및 순환 오류를 노드별로 표시한다.
- 새 UAnimAsset 생성 시 기본 Layer Graph와 LayerOutput을 함께 생성한다. Unity 7의 AssetCreationEndAction API를 사용한다.
- 저장 시 검증·컴파일하고 의존성 해시로 정의 변경을 표시한다.
- 한 Animator의 중복 출력 소유권을 거부하고 int 파라미터의 32비트 정밀도를 유지한다.
- 프리뷰 모델은 비활성 부모 아래에서 복제해 사용자 스크립트가 실행되기 전에 비활성화한다. 프리뷰 Scene 등록과 카메라 프레이밍을 보완했다.
- 두 캐릭터의 Idle↔Locomotion, Walk/Run Blend1D, 상체 Aim 및 AvatarMask 예제를 생성했다.
- 데모의 중복 전이 규칙을 수정하고 Windows 빌드와 실행을 검증했다.

## 직접 검증하지 못한 항목

네이티브 subgraph State를 **마우스로 생성·편집한 뒤 Undo/Redo하는 과정**과 그래프 강조 표시의 최종 화면 검증은 남아 있다. 컴퓨터 제어 도구가 Unity 창 조회 후 화면 캡처 승인 대기와 창 활성화에서 timeout을 반환해 직접 조작을 완료하지 못했다.

네이티브 State 연결은 공개 ISubgraphState API로 읽도록 구현되어 있다. 명시적 Pose State 참조 방식과 그래프 저장·재열기·임포트 경로는 검증됐다. 미검증된 마우스 조작 결과는 완료로 간주하지 않았다. 직접 확인용 Open Native State Verification과 Verify Authored Native States 메뉴를 추가했다.

## 사용

1. Assets/UAnimGraph/Demo/Demo.unity를 열고 Play를 누른다.
2. UAnimGraph > Open Demo Preview로 복제 모델 프리뷰를 연다.
3. Window > UAnimGraph > Preview and Debug의 Live Debug Target에 실행 중인 UAnimGraphPlayer를 지정한다.
4. 새 에셋은 Assets > Create > UAnimGraph > UAnimAsset에서 만든다.

상세 사용법: 실제 프로젝트의 Assets/UAnimGraph/README.md.
Windows 실행 파일: Build/UAnimGraphDemo/UAnimGraphDemo.exe.

후속 정리에서 참조 없는 이전 코드 18개(Mixer2D.cs 포함)를 삭제했으며, 기존 테스트 장면의 런타임 의존성과 예제·템플릿은 유지했다. Unity 빌드 과정에서 URP 및 일부 프로젝트 설정 파일이 해당 Unity 버전에 맞게 자동 재직렬화됐다. UnityConnectSettings의 원래 설정은 복원했다.

기획서의 후속 범위인 2D Blend, 중첩 상태 머신 실행, Any State, 전이 중단, 애니메이션 잡과 네트워크 동기화는 이번 MVP에 포함하지 않는다.

## 후속 미사용 코드 정리

참조 없는 C# 코드 18개와 companion .meta를 제거했다. 기존 테스트 장면이 이전 UAnimGraphComponent를 참조하므로 해당 런타임 의존성은 유지했다. 제3자 예제 및 URP 템플릿도 자체 장면/에셋 참조가 있어 보존했다. 장면, 모델, 애니메이션, manifest는 변경하지 않았다.

기존 에셋 GUID 참조 검사와 Unity 7000.0.0a9의 동일 컴파일러·참조를 사용한 UAnimGraph.Runtime/UAnimGraph.Editor 독립 컴파일은 통과했다. 배치 모드 검증은 사용자가 열어 둔 Unity 세션 때문에 실행되지 않았으며, 이번 삭제 후 33개 테스트를 재실행했다고 간주하지 않는다.

자동 승인 검토가 장면 수정·예제 에셋 삭제·패키지 설정 변경을 포함하는 확대 정리를 요청 범위 밖으로 판단해 거부했으므로, 해당 범위는 실행하지 않았다.
