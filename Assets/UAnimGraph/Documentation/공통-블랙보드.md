# 공통 블랙보드

같은 `.uanimasset`의 루트, StateMachine, State Pose Graph 창은 루트 Parameters를 편집하는 **Shared Blackboard** 패널을 사용한다. 각 그래프의 기본 블랙보드를 공유하도록 Unity 내부를 수정하는 방식 대신, 공개 Overlay API로 하나의 원본 데이터를 표시한다.

- 그래프 창에서 자동 표시한다. 숨겼다면 상단 **Shared Blackboard** 버튼으로 다시 표시한다.
- `+`에서 Float, Int, Bool, Trigger, Vector2 파라미터를 추가한다.
- Name과 Default를 편집하면 모든 하위 그래프 패널에 반영한다. 이름 변경 시 ID는 유지한다.
- Pose Graph의 **Create Node**는 해당 ID와 타입을 가진 Parameter 노드를 생성한다. 이 노드의 Value 출력을 믹서 등의 입력에 연결한다.
- StateMachine에서는 같은 목록을 조회·편집하고 **Copy ID**로 참조할 수 있다. 코드 전이 함수는 기존 TransitionContext 파라미터 접근을 사용한다.
- 변경과 삭제는 Undo/Redo를 지원하며 루트 소스 파일에 저장한다. 삭제한 파라미터를 참조하는 기존 노드는 자동 삭제하지 않으며 기존 검증으로 누락을 알린다.
- 파라미터 타입은 생성할 때 선택한다. 기존 노드의 타입 연결을 깨뜨리지 않도록 목록에서 타입은 읽기 전용이다.

별개 UAnimGraph는 각각 별도의 목록을 유지한다. 실행 값은 기존대로 캐릭터의 UAnimInstance별로 분리된다. 기존 Graph Toolkit의 로컬 변수와 블랙보드 데이터는 삭제하거나 자동 변환하지 않는다. Overlay 메뉴에서 기존 Blackboard도 다시 표시할 수 있다.

레거시 외부 그래프를 정확히 하나의 루트가 참조하면 그 루트를 사용한다. 여러 루트가 같은 외부 그래프를 참조하면 잘못된 루트를 수정하지 않도록 자동 연결하지 않는다.
