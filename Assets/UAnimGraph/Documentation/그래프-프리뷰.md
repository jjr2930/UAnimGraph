# 그래프 안에서 애니메이션 프리뷰

1. 루트·StateMachine·State 포즈 그래프의 툴바에서 **Preview**를 누릅니다.
2. **Preview Model**에 Animator가 포함된 모델 프리팹 또는 씬의 캐릭터를 지정합니다.
3. **Start Preview**로 재생하고 **Pause / Resume**, **Stop**, **Time** 슬라이더로 제어합니다. Time 이동 시에는 일시정지됩니다.
4. **Loop Preview**와 **Preview Length**로 반복 구간을 지정합니다. 길이는 프리뷰 반복 구간이며 클립 재생 속도를 바꾸지 않습니다.
5. 패널 하단에서 블랙보드 값을 바꾸어 전이와 믹서 입력을 확인할 수 있습니다.

기본적으로 현재 열린 그래프를 재생합니다. State 포즈 그래프에서는 그 State만 재생하고, StateMachine에서는 해당 머신의 전이를 재생합니다. 루트에서는 전체 레이어를 재생합니다. **Preview Whole UAnimGraph**를 켜면 하위 그래프에서도 소유 루트 전체를 재생합니다.

모델 복제본과 임시 그래프 정의는 저장하지 않습니다. 복제본의 사용자 Behaviour를 비활성화하고 Animator만 평가하여 씬 원본을 변경하지 않습니다. 패널 종료·그래프 변경·어셈블리 재로드·Play 모드 전환 시 프리뷰 리소스를 정리합니다. 저장된 그래프나 클립이 변경되면 프리뷰를 정지하고 새 정의를 연결하므로 Start Preview로 다시 시작합니다.

프리뷰의 재생은 에디터에서 별도로 수행됩니다. 실행 중인 게임 오브젝트 자체를 관찰하려면 기존 Live Debug Target 기능을 사용합니다. 그래프를 수정한 뒤 저장하고, 유효한 클립과 모델의 Animator/Avatar를 지정해야 합니다.
