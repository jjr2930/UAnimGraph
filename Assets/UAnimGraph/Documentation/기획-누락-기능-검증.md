# 기획서 미구현 기능 보완

기준: `UAnimGraph-기획서.html` v0.13의 Mixer 공통 Inspector 요구사항. 초기 v0.1 Markdown과 최신 HTML의 trigger 수명 규칙이 다르므로 최신 HTML을 기준으로 유지했다.

## 구현

- 파라미터를 이름으로 검색해 선택한다. 대소문자 구분 없이 부분 검색하며 한글 이름을 지원한다. Float/Vector2/XY 각각 맞는 타입만 선택할 수 있고 저장값은 기존의 안정적인 ID다. 검색창을 연 뒤 선택한 Mixer나 루트가 바뀌면 이전 검색 결과를 적용하지 않는다.
- Mixer의 `Open State duration settings`가 현재 Pose 그래프를 다시 여는 오류를 수정했다. 선택한 루트에서 실제로 해당 그래프를 사용하는 StateMachine을 연다. 공유 그래프라면 대상 State를 목록에서 선택하며, 각 State의 기준 시간도 표시한다. 연결된 State가 없으면 버튼을 비활성화하고 이유를 안내한다.
- Inspector 헤더에 선택한 Mixer의 오류·경고 개수를 표시한다. 미연결 입력은 경고, 중복 샘플 좌표는 오류로 분류해 네이티브 그래프 진단과 일치시켰다.

## 사용

Mixer Inspector에서 Parameter root를 지정하고 Input source를 파라미터로 변경한 뒤 파라미터 선택 버튼을 누른다. XY 바인딩은 X/Y 각각 검색할 수 있다. State 기준 시간은 `Open State duration settings`로 이동해 해당 State에서 설정한다.

재검증 메뉴: **UAnimGraph → Verify Planned Mixer Editing**.
