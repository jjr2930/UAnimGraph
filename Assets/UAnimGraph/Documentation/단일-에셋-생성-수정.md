# UAnimAsset 생성 중복 수정

새 UAnimAsset 생성 메뉴는 루트와 기본 Layer Graph를 한 개의 `.uanimasset` 안에 저장한다. 컴파일된 기본 Pose 그래프는 내부 객체로 보관하고 Project 계층에서는 숨긴다. 별도의 `.asset` 또는 `.uapose` 파일을 자동 생성하지 않는다.

루트 에셋을 더블클릭하거나 Inspector의 Open 버튼으로 기본 그래프를 편집한다. 파라미터·레이어 설정도 같은 에셋에 저장된다. 기존 분리형 `.asset` + `.uapose` 에셋은 그대로 지원한다.

검증: 생성 한 번의 소스 에셋 수 1개, Project에 노출되는 객체 수 1개, 독립 생성 ID, 설정 저장·재열기, 재임포트, 실제 애니메이션 출력, 이름 변경 후 참조 보존 모두 통과했다.
