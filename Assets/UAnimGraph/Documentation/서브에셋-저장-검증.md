# UAnimAsset 내부 저장

## 변경

Layer의 Create State Machine과 State의 Create State Pose Graph는 독립 저작 파일 대신 루트 `.uanimasset`의 `embeddedSources`에 원본을 저장한다. 컴파일된 UAnimMachine과 UAnimPoseGraph는 동일 루트 경로의 실제 서브에셋으로 생성한다. 루트를 펼치거나 자식 서브에셋을 더블클릭해 편집할 수 있다. 미완성 Layer 때문에 루트 연결이 유효하지 않아도 이미 만든 내부 그래프는 유지한다.

Unity 7000.0.0a9의 공개 CreateLocalSubgraphNode API는 StateMachine 파생 형식을 거부한다. 네이티브 편집기를 계속 사용하기 위해 `Assets/Editor/UAnimGraphCache/<root-guid>`에 편집 캐시를 재생성한다. 저장 시 캐시의 변경을 루트 원본에 반영한다. 이 폴더는 버전 관리 대상이 아니며 삭제 후 에디터에서 자동 복구된다. 플레이어 실행 정의는 이 캐시를 참조하지 않는다. Animator·클립·AvatarMask 같은 외부 참조는 기존 Unity 에셋을 사용한다.

기존 외부 그래프를 내부화하는 메뉴: 루트 선택 → Assets → UAnimGraph → Embed Referenced State Graphs. 일반 메뉴는 외부 원본을 삭제하지 않아 다른 루트의 공유 참조를 보존한다. 명시적 PoseState 참조를 내부화하며, 기존 네이티브 외부 subgraph State의 참조 방식은 유지한다.

## 검증

- 신규 14개 통과: Machine/Pose 내부 생성, 같은 에셋 경로의 서브에셋 확인, 클립 참조, 단일 원본 파일, Animator 실행, 캐시 삭제·복구 후 ID와 정의 해시 유지, 루트 복제 후 편집 독립성, 이름 변경.
- 기존 통합 41개 및 기본 회귀 33개·루트 연결 검증 통과.
- 기존 사용자 루트의 복제본 이전 검증 통과: Machine·State ID, 내부 Pose 참조 유지, 추가 검증 오류 없음. 이미 미완성이던 Layer 설정은 그대로 보존.
- 로그: `.validation-project/Logs/EmbeddedFinal.log`, `UAnimGraph-embedded-verification.txt`, `EmbeddedUserMigration3.log`.

실제 프로젝트의 `Assets/UAnimGraph/Tests/UAnimAsset.uanimasset`에도 이전 결과를 반영했다. 다른 에셋의 GUID 참조가 없음을 검사한 뒤 `UAnimAsset-Layer.uamachine`과 `State.uastate` 및 두 `.meta`를 제거했다. 원본 여섯 파일은 기획 작업공간의 `tmp/embedded-user-snapshot`에 보관했다. 다른 예제·모델·클립은 변경하지 않았다.

이번 검증은 배치 자동 검사다. 네이티브 편집기의 최종 마우스 조작 화면과 새 Windows 플레이어 빌드는 별도로 실행하지 않았다.
