# UAnimGraph 에셋 만들기

현재 사용하는 루트 에셋은 **UAnimAsset**, 실행 컴포넌트는 **UAnimGraphPlayer**입니다. 이전 실험용 메뉴의 `Asset` / `UAnimGraphAsset`과 구분하세요.

## 1. 단일 애니메이션부터 실행하기

1. Unity의 Project 창에서 저장할 폴더를 선택합니다.
2. 우클릭 → **Create → UAnimGraph → UAnimAsset**을 선택하고 `CharacterAnim`처럼 이름을 정합니다.
3. `CharacterAnim.uanimasset` 파일 하나가 만들어지며 기본 Layer Graph와 LayerOutput은 내부에 저장됩니다.
4. 루트 Inspector의 **Open / … / Base Layer** 버튼이나 루트 에셋 더블클릭으로 내부 그래프를 엽니다.
5. 그래프의 생성 메뉴에서 **Clip** 노드를 추가합니다. 검색에서 `Clip`을 찾으면 됩니다.
6. Clip 옵션에 AnimationClip을 지정합니다. FBX에 들어 있는 애니메이션이라면 Project 창에서 FBX를 펼친 뒤 내부의 클립을 선택합니다.
7. Clip의 **Pose 출력 → LayerOutput의 Pose 입력**을 연결하고 저장합니다.
8. 루트 에셋으로 돌아와 **Validate / Compile**을 누릅니다.

처음 생성한 그래프는 출력이 연결되지 않아 오류가 표시될 수 있습니다. Clip을 연결하고 저장하면 해소됩니다. LayerOutput은 하나만 둡니다. 기본 레이어는 Weight 1, Additive 해제, Mask 없음으로 유지합니다.

## 2. 캐릭터에 적용하기

1. Scene의 캐릭터에 **Animator** 컴포넌트가 있는지 확인합니다. Humanoid 캐릭터라면 모델의 Rig와 Avatar도 올바르게 설정합니다.
2. Animator의 **Controller를 None**으로 설정합니다.
3. **UAnimGraphPlayer** 컴포넌트를 추가합니다.
4. Player의 **Asset**에 방금 만든 루트 `.uanimasset`을 넣습니다.
5. **Animator**에 해당 캐릭터의 Animator를 연결합니다.
6. Play를 누릅니다. 한 Animator에는 하나의 UAnimGraphPlayer만 사용합니다.

기존 `Assets/UAnimGraph/Tests/Scenes/TestScene.unity`에는 이전 실험용 UAnimGraphComponent가 남아 있습니다. 이 장면에서 새 구현을 사용할 때는 이전 컴포넌트를 제거하고 UAnimGraphPlayer를 사용해야 합니다. 기존 모델·애니메이션은 그대로 사용할 수 있습니다.

## 3. Idle ↔ Move 상태 머신 만들기

1. **Create → UAnimGraph → State Pose Graph**로 `Idle.uastate`를 만듭니다.
2. 내부에 **Clip(Idle) → StateOutput**을 연결합니다. StateOutput의 **Duration**은 원하는 상태 재생 기준 길이(초), **Speed**는 기본 1로 지정합니다.
3. 같은 방법으로 `Move.uastate`를 만들고 이동 클립을 연결합니다.
4. **Create → UAnimGraph → State Machine**으로 `Locomotion.uamachine`을 만듭니다.
5. 머신에 **Pose State**를 두 개 추가하고 이름을 Idle, Move로 바꿉니다.
6. 각 Pose State의 **Graph**에 해당 `.uastate`를 지정합니다. Idle의 **Default**만 켭니다.
7. Idle→Move, Move→Idle 전이를 연결합니다.
8. 기존 Layer Graph에 **StateMachine** 노드를 추가하고 Machine에 `Locomotion.uamachine`을 지정합니다.
9. **StateMachine.Pose → LayerOutput.Pose**를 연결합니다. 기존 Clip→LayerOutput 연결은 제거합니다.

### Speed로 전이 제어하기

루트 Inspector의 Parameters에 다음 파라미터를 설정합니다.

| 항목 | 값 |
| --- | --- |
| id | `speed` — 다른 파라미터와 겹치지 않는 고정 ID |
| name | `Speed` |
| type | `Float` |
| defaultValue | `0` |

각 전이의 **기본 규칙 하나**에 AND 조건을 추가합니다. UAnimGraph의 **Parameter ID \| Type \| Comparison \| Value** 조건을 선택하고 아래 값을 넣습니다.

- Idle → Move: `speed|Float|Greater|0.1`
- Move → Idle: `speed|Float|LessOrEqual|0.1`

**Duration Seconds** 조건에 `0.2`를 넣으면 0.2초 CrossFade입니다. 규칙은 하나의 AND 그룹을 사용하며, OR가 필요하면 별도의 전이로 나눕니다.

실행 중 `UAnimGraphPlayer.SetFloat("speed", 값)`으로 속도를 바꿉니다. 프리뷰·디버그 창에서도 파라미터를 조절할 수 있습니다.

## 4. Walk ↔ Run 블렌드 추가하기

Move의 State Pose Graph에서 다음과 같이 연결합니다.

- Clip(Walk) → Blend1D.Pose0
- Clip(Run) → Blend1D.Pose1
- Parameter → Blend1D.Value
- Blend1D.Pose → StateOutput.Pose

Parameter 노드는 **ParameterId = speed**, **Type = Float**으로 설정합니다. Blend1D의 Count는 2, Threshold0은 예를 들어 0.1, Threshold1은 2로 설정합니다. 임계점은 반드시 작은 값부터 증가해야 합니다.

## 5. 프리뷰와 예제

- 루트 Inspector의 **Preview / Debug** 또는 **Window → UAnimGraph → Preview and Debug**를 엽니다.
- Root Asset과 Preview Model을 지정하고 **Start Preview**를 누릅니다. 원본 Scene을 바꾸지 않는 복제본에서 재생합니다.
- Play 모드에서는 **Live Debug Target**에 캐릭터의 UAnimGraphPlayer를 지정해 현재 State와 가중치를 확인합니다.
- 완성된 예제: `Assets/UAnimGraph/Demo/Demo.asset`, `Assets/UAnimGraph/Demo/Demo.unity`.
- 빠르게 예제 프리뷰 열기: **UAnimGraph → Open Demo Preview**.

그래프를 수정한 뒤 저장하고 루트의 Validate / Compile을 실행하세요. 실행 중 정의 변경 경고가 나오면 Player나 프리뷰를 재시작합니다.
