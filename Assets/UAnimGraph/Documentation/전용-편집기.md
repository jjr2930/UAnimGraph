# UAnimGraph 전용 편집기

## 열기

- **Window → UAnimGraph → Graph Editor**
- 프로젝트에서 그래프 에셋을 더블클릭하거나 **Assets → UAnimGraph → Open Graph Editor**를 선택합니다.
- 기존 **Authoring Workspace** 메뉴도 전용 편집기로 연결됩니다.
- `New`로 기본 Layer·StateMachine·State Pose Graph가 연결된 루트 에셋을 만듭니다.

## 화면과 조작

왼쪽은 루트·레이어·StateMachine·State 탐색과 공유 블랙보드, 가운데는 전용 캔버스, 오른쪽은 선택 항목 Inspector와 애니메이션 프리뷰입니다. 분할 경계를 드래그해 패널 크기를 조절합니다.

- 빈 공간 우클릭 또는 `+ Add`: 노드·State 생성
- 노드 드래그: 위치 이동
- 휠: 확대/축소, 가운데 버튼 또는 Alt+드래그: 화면 이동, `F`: 전체 보기
- 같은 타입의 출력·입력 포트를 연결: Pose/값 연결. 입력을 다시 연결하면 기존 연결을 대체합니다.
- 포트/와이어 우클릭: 연결 해제
- 노드 더블클릭 또는 Open 버튼: 내부 그래프 열기. 이름 입력란의 더블클릭은 텍스트 편집으로 남습니다.
- `Transition →` 또는 State 우클릭의 Create Transition 후 목적지 클릭: 전이 생성
- 전이 선/화살표 클릭: 해당 전이의 함수·Duration·Priority·Self 설정
- `Delete`: 선택 항목 삭제, Unity의 Undo/Redo 사용 가능
- `Save`: 저장, `Validate`: 현재 루트의 실행 가능 여부 확인

## 믹서와 파라미터

Mixer1D에는 포즈별 임계값, Mixer2D에는 포즈별 X/Y 좌표가 표시됩니다. 기본 두 입력은 삭제할 수 없고 Add Input Pose로 추가합니다. Inspector에서 Graph Port·파라미터·상수 입력과 Natural Clip Timing을 설정합니다.

공유 블랙보드는 루트 기준입니다. 프리뷰가 실행 중이면 Live 값을 바꾸며 전이/블렌딩을 확인하고, 실행 중이 아니면 기본값을 편집합니다. 파라미터 노드와 믹서의 파라미터 선택은 이름으로 표시하며 내부 연결은 안정적인 ID를 사용합니다.

## 프리뷰와 런타임 확인

Preview Model에 Animator/Avatar가 있는 캐릭터를 지정하고 Start Preview를 누릅니다. Pause/Resume·Stop·Time·반복 구간을 지원합니다. Whole UAnimGraph로 현재 하위 그래프와 루트 전체 재생을 전환합니다. 모델은 복제본에서 재생하고, 선택한 모델은 탐색/창 전환 후에도 유지합니다.

실제 Play 중인 캐릭터는 Live Debug Target에 지정합니다. 활성 노드/State 및 실행 중인 전이는 초록색으로 강조되며, 믹서 Inspector와 프리뷰 패널에서 입력 가중치·상태 시간·전이 진행률을 확인합니다.

## 호환 범위

편집 화면은 자체 UI Toolkit 캔버스와 Inspector로 구성하며 GTK의 노드 뷰·창·오버레이·가시화 컨텍스트를 만들지 않습니다. 기존 `.uanimasset/.uamachine/.uastate/.uapose` 파일과 런타임/플레이어 참조를 유지하기 위해 GTK의 공개 데이터·저장·컴파일 API는 호환 어댑터에 남아 있습니다. 파일 포맷 전체를 새로 이관하거나 런타임 지원 범위를 확장하는 변경은 아닙니다.

사용자 테스트 그래프를 변환 없이 여는 검사와 파일 무변경 검사, 노드/전이/포트/믹서/Undo/저장 및 실제 Idle→Run 실행 검사, GTK 그래프 창을 열지 않는 UI 검사를 수행했습니다.
