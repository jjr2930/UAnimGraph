# 코드 컨벤션 적용

범위: Assets/UAnimGraph의 자체 C# 코드 78개 파일을 검사하고 77개 파일의 형식을 정리했다. 외부 패키지와 Unity 샘플은 변경하지 않았다. 기획 공간의 Implementation/Editor 및 Runtime도 같은 규칙으로 정리하되 별도 검증 코드의 기존 변경사항은 유지했다.

- Allman 중괄호, 공백 4칸 들여쓰기
- 한 줄 제어문에 중괄호 추가: 675곳
- 표현식 본문 메서드/생성자/프로퍼티/접근자를 중괄호 본문으로 변경: 97곳
- if(...) 등 제어문 키워드 뒤 공백 제거
- 람다·switch 표현식 유지

검증: C# 문법 분석을 사용한 변환, 변환 결과의 토큰 및 문자열·주석 보존, 재실행 시 변경 없음, 표현식 본문과 중괄호 없는 제어문 잔여 0개. Unity 컴파일 경고·오류 0개. 공통 블랙보드, 기본 머신 생성, 전이 UI, 임베디드 복원, 전체 기능 및 실제 Animator 그래프 실행 검사 통과.

원본과 해시 목록은 기획 공간의 tmp/conventions/before 및 manifest.json에 보관했다. 검증 로그: 실제 프로젝트 Logs/CodeConventionsFinal.log.
