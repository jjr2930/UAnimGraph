# UAnimGraph 폴더 구조

- `Runtime/`: 플레이어, 그래프 인스턴스, 상태 머신, 포즈, 블랙보드, 전이 평가.
- `Runtime/Samples/`: 예제 전이 함수와 데모용 컴포넌트.
- `Editor/`: Graph Toolkit 저작 도구, 임포터, Inspector, 프리뷰·디버그.
- `Editor/Samples/`: 예제 그래프·씬 생성 도구.
- `Editor/Tests/`: 에디터 검증과 회귀 검사.
- `Documentation/`: 사용 안내와 변경·검증 기록.
- `Tests/` 및 기존 예제 에셋 폴더: 사용자가 만든 테스트 씬, 애니메이션, 그래프 및 예제 에셋.

기존 MVP 폴더의 코드를 정식 Runtime·Editor 폴더로 이동했습니다. 대체된 초기 `UAnimGraph.Runtime`·`UAnimGraph.Editor` 구현과 해당 구현 전용 검증 코드는 제거했습니다.

파일의 `.meta`를 함께 이동하고 현재 사용하는 `UAnimGraph.Core`·`UAnimGraph.Authoring` 어셈블리 이름을 유지하여 씬의 컴포넌트 참조와 그래프의 직렬화된 타입을 보존합니다.
